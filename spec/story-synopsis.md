# 《基督山伯爵》故事梗概（前三卷·共47章）

> 架空古代复仇小说 | 改编自大仲马《基督山伯爵》 | 前三卷约23万字

---

## 一、故事前提

十年前，北魏兴城。商人之子**黄简**与**林玄影**是从小一起长大的兄弟，两人同时爱慕李家大小姐**李素节**。林玄影在跑商归途中写了一封匿名举报信举报黄简通敌——只为拖延黄简几日，自己先去表白。在他想来，信到县衙，关两天就放了。

信在驿站被人截下，落入了时任县尉**陈伯庸**之手。陈伯庸连夜将黄简跨州转至百里外的宣城监狱——一座专关"该被遗忘之人"的死牢。随后与时任监军**顾从戎**联手，借大虫伤人事件伪造了黄简的死亡——用黄简的衣物和玉佩布置假现场。全兴城都相信黄家公子被老虎咬死了。

黄母闻讯疯了，五年后离世；三月后黄父自缢。林父不知从谁手中拿到了举报信原件，发现儿子害死了黄简，当场惊悸而亡。陈伯庸则从县尉一路升至兴州刺史，修桥铺路、赈灾济贫，民间口碑"爱民如子"。

十年后，黄简逃出了宣城监狱。狱中一位西蜀老人教了他十年风水、相术、符箓、权谋。老人临终前说出西蜀青松观后山藏有财富。

## 二、三卷叙事逻辑

三卷回答一个问题：**一个死过一次的人，怎么向一个"完美清官"讨还血债？**

| 卷 | 核心任务 | 逻辑递进 |
|----|---------|---------|
| 一·囚徒脱壳 | 活下来，知道该恨谁 | 真相拼图 → 锁定仇人 → 决定复仇 |
| 二·荒野寻踪 | 攒资本，摸清对手 | 财富+知识+情报网 → 第三卷的武器系统 |
| 三·佛口蛇心 | 精密布局，拽下神坛 | 舆论战 → 反向渗透 → 鬼魂审判 → 首杀 |

## 三、第一卷·囚徒脱壳（第1-15章）

**核心问题：黄简怎么活下来，以及怎么知道自己该恨谁。**

黄简在宣城监狱关了十年。同牢的西蜀老人教了他风水、命理、符箓、药理、权谋——老人管这些叫"无用之学"。临终前说出藏宝地和开启之法。黄简剃发换衣，把尸体穿上自己的囚服，自己裹进草席冒充老人尸体。狱卒将他抬出扔进乱葬岗。他爬出来，翻山越岭，偷渡入陈汉国。

在宁州城，他用老人教的相术和风水知识诊断客栈掌柜儿子的病因（房间布局犯煞），调整后三日见效。掌柜感激之余为他办下新身份文书——**黄繁**，陈汉国行脚商人。

黄繁回到兴城。故宅已变"陆宅"，父母双亡。当夜翻墙入林宅——林玄影酗酒度日，每隔几日便看见黄简的"幻觉"。他把黄简当成又一次幻觉，毫无防备地聊了起来。黄简套出：信是林玄影写的。暴怒过后，两人坐下来拼图——**信在驿站就被拦截了，根本没有送到县衙**。李县令从头到尾不知情。来抓人的是军营的人，黄简被连夜跨州转移。顾从戎对李家编造"人在乐城已释放"。山道上的大虫现场——只有外衣碎片和玉佩，没有一片里衣。结论：**林玄影的信只是火星，柴是别人早堆好的。**

林玄影两年调查拼出关键线索：县尉陈伯庸十年内连跃数级升至刺史——升迁速度不正常。当年举报信原件被人从县衙档案调包——有人专要让林父知道是儿子害了黄简。同时牵出了陈伯庸的侄子**陈新豪**（宣城监狱狱监）和矿山招工失踪案之间的可疑关联。

第十五章末，黄简说："从今往后——黄家的黄简已经死了。外面走着的这个人叫黄繁。该还的债，黄繁会替他还。"他决定去西蜀取老者留下的东西；林玄影留守兴城盯着陈伯庸。

## 四、第二卷·荒野寻踪（第16-30章）

**核心问题：怎么从零开始攒够复仇的资本？**

第二卷双线交替：黄繁西蜀寻宝（A线），林玄影兴城建情报网（B线）。

**A线·寻宝**：黄繁以行脚商人身份上路。在集镇买骡子时迎面撞上当年看守他的老狱卒——互相认出，但老狱卒选择沉默。入西蜀后以堪舆术定位岭山青松观：先找错了几处，后退到高处观察地形，结合"坎位属水、北面偏西"锁定西北深沟。找到庙后老槐树——根绕三圈、每圈六瘤、第五瘤有"人"字裂纹。丑时以铁钉开启机关：第一钉卡住（钉错位置），分析后找到凹陷底部的金属槽口，第二钉入，三声脆响，地面裂开。

密室三层结构本身是一场筛选：表面层金银箱（够兴城站稳脚跟），隐藏层书匣（破陶罐烂麻袋下，老者毕生著述），最深层坎位暗格中的石匣（印章、信件、令牌——老者说"烧了"，却藏在最隐秘处）。黄繁伪装成山货商人将东西运回，遇西蜀礼神日边境关闭，以王家玉商令牌通关。

**B线·情报网**：林玄影以行商经纪身份重建人脉。收留少年**周顺**——父亲几年前出门做工再未归来。周顺跑腿时撞见矿上招工——"管吃管住工钱高，无家庭牵绊优先"。林玄影派人跑遍十三村：七个有招工，去了的人部分被蒙车帘送去送回（不让说矿在哪），部分再无音讯。小厮伪装落魄人试探，招工的立刻盯上。几天后林家杂货铺被纵火——小厮被人反跟了。

**合流**：黄繁回兴城。两人信息对接——黄繁记得狱卒说过"新狱监是刺史亲戚"（陈新豪），林玄影查到招工方向指向宣城。**线索锁死：矿山是陈伯庸和陈新豪私下运作的，与宣城监狱失踪囚犯同模式。** 两人设定书局夹纸条为联络方式。数月经营：黄繁实战练习观人术和权谋术，林玄影人脉铺进镖局、钱庄、书塾、商会，周顺管理二十多跑街孩子的情报网。

卷末，矿山招工在数月前全面停止——所有村子同时停，无一人返乡。"不能再慢了。"

## 五、第三卷·佛口蛇心（第31-47章）

**核心问题：怎么让全城爱戴的"好官"从神坛上摔下来，并让他亲口说出当年对黄家做了什么？**

### 阶段一：起风——以祥瑞为切口（第31-33章）

**为什么从祥瑞入手？** 陈伯庸民间口碑铁板一块。直接翻旧案，百姓不会信。必须从他力推的公共事件撬开口子。

陈伯庸办祥瑞启程大典——在乌岭"发现"了一块血红奇石上表朝廷。黄繁观察到：祥瑞发现地阳坡三个村子无人传出发现奇石的消息；人群中有一个右手缺了半截小指的老汉在往外走。他让周顺盯着这个老人。

邳州失踪者家属进兴城寻人——这是林玄影大半年前沿商路撒下的口信。陈伯庸以"发文查访+管吃管喝+警告不得生事"化解。黄林反击：派镖工确认宣城白沟梁矿场（围墙新刷石灰、三村男丁不齐），从府衙批文堆翻出陈伯庸对陈新豪的亲笔批注。第二波消息直接点名"宣城白沟梁""陈新豪""乐城销金窟"。陈伯庸当夜派人让陈新豪出逃。

### 阶段二：切割——逼对手自己撕开口子（第34-36章）

**为什么不能让他躲在"被侄子蒙蔽"后面？** 那样他只是糊涂官，不是罪人。必须逼他公开表态，让他说出的话限制他的退路。

陈伯庸公开切割：告示宣布"被蒙在鼓里痛心疾首"，自请罚俸、捐俸赈济、城隍庙便服施粥。百姓感动落泪。但切割等于公开承认矿山与己有关——此后任何矿山爆料自动挂上他的名字。

林玄影多次接触断指老人。老人曾是文顺粮铺仆人，讲出粮荒完整真相：外路人深夜寄存粮→天没亮官差直奔后院（知道粮在哪）→东家凭据被袖走→当天正法→家人发配路上"遭匪"全死→原刺史死于混乱→陈伯庸站出来赈灾→几月后升刺史。后来老人认出当晚放粮的外路人跟在陈伯庸身后出府。核心逻辑：**粮荒是人为制造——封粮道囤粮→栽赃粮铺平民怨→除掉原刺史→以赈灾英雄上位。**

周顺去矿山布鬼，在山凹发现石灰覆盖的新土——底下是万人坑。

### 阶段三：收紧——两边抢时间（第37-40章）

**为什么这一步必然发生？** 流言从"矿上闹鬼"升级到"粮荒旧账"，陈伯庸必然全力追查。黄林必须在他追到之前保护证人，并确保查到的人不是做主的人。

矿上闹鬼传进兴城。陈伯庸上山找到人为装置，确认为人为。府里绘图工**顾渔**（口吃，擅长空间推演）进黄繁铺子——进门先看布局而非货，注意到柜子与墙之间的夹层。黄繁察觉此人不寻常。

京城御史在朝会质疑祥瑞来源。三皇子施压要陈伯庸拿更实在的背书——陈腹背受敌。

周顺被跟踪，甩掉后报信。林玄影启动全线撤退：断指老人连夜转移，外围出城避风，京城/邳州线继续，兴城一切与陈沾边的事全停。在书局夹决绝字条给黄繁："这边几日无信，你自断，不等。"

陈伯庸追查到：周顺跟林玄影有关，断指老人被认出是文顺粮铺老仆。下令抓林玄影和另一个行商经纪。但老人住处已空。

林玄影白天被刺史府护院当街抓走——**没走公堂，说明陈伯庸没有可以摆上公堂的实证。** 围观人群中与黄繁交换一秒眼神。黄繁决定：铺子照开，外面线继续动——**如果抓了林玄影外面的消息就停了，陈伯庸就抓对人了。**

### 阶段四：渗透——反向利用对手的掌控（第41-43章）

**为什么林玄影要主动投靠？** 陈伯庸不杀他的唯一理由，是觉得他还有用。那就让自己"有用"——被怀疑的人主动走进怀疑者的院子，比躲在外面更安全。

审讯中陈伯庸扮红脸。林玄影答三层：承认做消息生意、主动表态愿替陈效力（打听/传话/过账）、对"背后有没有人"——"要真有那个本事，也不至于做这点小本生意"。陈伯庸决定留前院"先用着"。

林玄影在饸饹面摊用闲聊向外传信号——"人家一看这人也有点用就给留下了"——黄繁听懂了：安全，计划继续。

陈伯庸交办三件事，林玄影件件反向操作：查搅局者报上去的全是市井常识；筹钱——活钱确实押在商队取不出来（早有准备）；放话——派伙计夸张夸"刺史是好官"，反而激起茶客翻更多旧账。盯他的人最终撤了——"就是个做小买卖的"。

林玄影在府里观察到：陈伯庸白天"自救"夜里收拾细软（准备逃）；京里贵客今年一天就走（三皇子要弃子）；偏门亥时前后没巡逻。第二次面摊信号——"今晚去收账，正门闩了走偏门"——黄繁回应："亥时就到了。"

### 阶段五：执行——鬼魂审判与首杀（第44-45章）

**为什么用"鬼神"而非直接刺杀？** 直接刺杀只有快感，没有信息。黄简需要陈伯庸亲口说出当年发生了什么。兴城人信鬼神——在迷香、灰烬、铜器声和被堪舆术布置的声场中，一个人面对"不可欺骗的存在"时防线才会崩溃。

亥初。林玄影开偏门放黄繁入府。黄繁用老者堪舆术布置：引魂香烟从窗缝渗入，朱砂纸符灰絮飘入书房，铜碗放在兑位（西，属金，主杀伐）以铜丝牵动发声。陈伯庸闻到气味、看到暗红灰烬、听到西墙铜器声——精神防线崩溃。

"陈伯庸，你可知罪。"从"我陈伯庸为官二十年谁不说好"到一句句吐出：粮荒人为制造、祥瑞是假的、大将军被伏击是他和顾从戎替三皇子办的、"黄家那小子看见了不该看的人"。当意识到是人为后转为攻击——"有的你永远够不着，有的永远想不到"。黄简抹掉脸上灰——"陈大人不认识我了吗？"一刀刺入胸口。首杀。

两人伪造自裁现场（匕首塞手+书吏代笔遗书），带走陈伯庸包袱中的密文账本。事后在小院碰面：林玄影坦承当年对陈伯庸的人说过黄家的事。"我后来家破人亡，是我活该。"黄简："你不说，也会换一个人问。他们本来就是要动黄家的。"

### 阶段六：余波——复仇之后（第46-47章）

**为什么复仇成功之后黄繁反而陷入虚无？** 因为杀死陈伯庸没有带来预想的"痛快"。那个人甚至记不清自己害过多少人。

杀手回京复命。三皇子见遗书未攀咬，顺势"人死债消"。朝堂议定：祥瑞不追，粮荒/矿山/陈新豪案严查，陈家人流放苦役。

黄繁一个多月没缓过来——匕首刺入的触感自己会来。街面上翻出了陈伯庸全部罪名。断指老人坐在街口剥豆子，有人给他搬米。李希音找林玄影，不是来问真相的——"这几年我什么都没干，有个由头怨着。现在由头没了。"周顺去矿山收骨——带回刻着"周"字的短凿和母亲缝过的腰带。周母攥着腰带放声大哭："他不是那样的人。我就知道他不是。"

黄繁和林玄影最后一次碰面：账本暗记看不懂；顾从戎府邸戒备太严；三皇子以目前分量够不着。**"待在兴城已经没有意义了。"** 林玄影去京城，黄繁去西蜀——老者石匣中的印章、令牌、信件，也许能找到一个"能与权力平等对话的身份"。

最后画面：黄繁锁上铺门，去父母坟前放了一盒桂花糕。踩上碎石子官道，再没回头。

## 六、主要人物

| 人物 | 身份 | 作用 |
|------|------|------|
| **黄简/黄繁** | 商人子→死囚→行脚商人 | 从逃亡到复仇。三卷完成首杀，从被动受害转为主动追索 |
| **林玄影** | 黄简的童年兄弟，举报信写作者 | 以余生赎罪。建情报网、被捕后反向渗透——是刺杀成功的关键 |
| **陈伯庸** | 兴州刺史 | 三卷核心对手。表面"爱民如子"，暗地私矿/粮荒/替三皇子处理脏活 |
| **周顺** | 少年眼线，父亲死于矿山 | 底层视角的参与者。管理者、执行者、受害者家属——三重身份 |
| **陈新豪** | 陈伯庸远房侄子，宣城狱监 | 陈伯庸在矿山和监狱的"手" |
| **顾从戎** | 前兴城监军，现兵部侍郎 | 十年前与陈伯庸联手伪造黄简之死。在京城——下一阶段目标 |
| **三皇子** | 北魏三皇子 | 陈伯庸和顾从戎背后的人。第一卷末埋线（李素节嫁他），第三卷末露出手臂 |
| **李素节** | 黄简与林玄影共同爱慕的人 | 现为三皇子侧妃。三卷中仅通过信件和回忆出现，不直接出场 |
| **李希音** | 李素节之弟 | 不知情的局外人。用酒精麻痹自己数年，真相揭开时发现自己浪费了太多时间 |
| **顾渔** | 刺史府绘图工，口吃 | 灰色人物。能一眼看穿空间布局——包括柜子后的暗格。不站队，"看到有趣的事会留意" |
| **断指老人** | 文顺粮铺老仆 | 粮荒冤案的活证据。等了十几年落叶归根 |
| **老者** | 西蜀人，黄简的狱中老师 | 教了十年。死后留下财富、知识体系、和一个尚未揭开的过去 |

## 八、阅读引导

- **精密复仇**：不是"以德报怨"，也不是简单的以暴制暴。整个过程是层层递进的战略执行——舆论撬动→实证坐实→反向渗透→最后一刻让仇人面对自己。让掌权者从神坛上摔下来，比直接杀了他更彻底。
- **双主角制衡**：黄简和林玄影是童年兄弟，也是害与被害的关系。故事不追求"原谅/不原谅"的二元，而是展现更复杂的事实：两个人都被同一场阴谋碾碎了，要讨回来就得一起做。两人明面上从不接触，全程靠书局夹纸条和面摊隔空传话。
- **没有蠢货反派**：陈伯庸每一步反制都是理性的——公开切割抢占道德高地、同一夜追查所有消息源头、审讯中交替恐吓与怀柔、至死都在寻找对手的破绽。赢，是因为每一步都比对手多算了一步。
- **灰色人物群像**：主角会利用少年当眼线、会偷农民的衣服、会计较"杀还是不杀"——然后杀了。口吃绘图工顾渔能看穿一切空间布局，但"看到有趣的事，会留意"。每个人有自己的逻辑，没有工具人。

前三卷构成完整的第一阶段复仇弧——可独立阅读，也自然引出下一阶段：黄繁去西蜀寻找能与权力平等对话的身份，林玄影去京城铺设势力。三皇子、顾从戎、以及那个"每天都在见却绝不会怀疑的人"，还在等着他们。
