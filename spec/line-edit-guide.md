## 〇、开工前必做

1. 读本章正文全文。
2. 读相邻章（前一章结尾 + 后一章开头），核对衔接。
3. 跑一遍 A 节 grep 自查，先拿到问题清单。
4. 改完再跑一遍 grep 复查 + 通读一遍。
5. 保存 = 单独 `git add` 本章文件后 commit，**不要 `git add .`**（避免混入其他窗口/未完成的改动）。

## 一、grep 自查清单（改前 + 改后各跑一次）

```bash
f=chapter-0XX.md
echo "分隔线:" $(grep -cE '^---$' "$f")                    # 目标≈0，非必要不留
echo "破折号:" $(grep -c '——' "$f")                        # 只留对话中断，夹注全改
echo "突然忽然:" $(grep -cE '突然|忽然' "$f")                # ≤2，能删就删
grep -nE '不是.{0,12}而是|不再是.{0,12}而是|没有.{0,10}是的|不是.{0,8}，是' "$f"  # 红线，必清零
grep -nE '涌上|压下去|翻涌|按下不动|涌上心头|沉了一下|堵着一团' "$f"   # 情绪元描述 P-53
grep -nE '沉默|静了一阵|半晌|停了一下|顿了一下|愣了一下' "$f"       # 沉默/停顿家族
grep -nE '喉结|咽了口唾沫|深吸一口气' "$f"                    # 生理套路动作
grep -nE '声音(发紧|发涩|沉下|低下|一沉)|嗓子|嗓音' "$f"        # 声音标签，只留传新信息的
grep -nE '嘴角|眉头微|眼中闪过|嘴唇动了动|张了张嘴' "$f"        # 微表情堆叠 P-47
grep -nE '茶|酒' "$f"                                       # 饮品一致性（本卷统一为酒）
grep -nE '桂|柏|槐' "$f"                                     # 树种/意象核对
grep -nE '收紧|攥|抠紧|握紧|门框|门闩' "$f"                    # 反复动作扎堆检查（第10类）
```

## 二、十类必改问题（按优先级）

> **删除判断三问**（贯穿全节的通用尺子，拿不准删不删时过一遍）：
> 1. 这句删掉，读者还能从上下文推出发生了什么吗？能 → 删。
> 2. 这个动作/情绪，前面出现过吗？出现过 → 删或换个写法。
> 3. 这个反应符合该角色此刻的人设和处境吗？不符 → 删或改。

### 1. 物理/设定一致性（硬伤，最优先）
- **饮品按场合定，不是一刀切全改酒**：叙旧/翻旧账/情绪重的场合用酒（ch10/11 那晚）；坐下来细聊正事、推演线索的冷静场合用茶（ch14/15）。判断场景基调再定茶/酒。**ch14→ch15 是同一夜连续场景，已定为茶**，别再改回酒。（对话中引用旧事的"茶/酒"按原语境，不动。）
- **家具**：本作是**凳子**，不是椅子。"椅背/扶手"全删，改桌面动作。
- **桂花树 = 黄家/李家专属意象**（承载黄简对母亲、李素节的回忆）。**不得**出现在林宅或泛写的院子景里。泛指用"院里的树"。
- **柏树叶 = 枝叶/鳞叶**，不是"针叶"（针叶是松）。
- **空间逻辑**：动作发生的位置要和人所在的空间吻合（坐桌边只能撞桌沿，不会磕到远处的书案角）。
- **道具追踪**：有重量有位置的东西（骡子、包袱、酒壶、钱袋）跨场景要交代去向。

### 2. 时间线 / 季节（跨章硬伤，写前必对表）
- **基准表**：spec/tracking-master.md「绝对时间轴」。关键锚点：
  - 10年·立秋 越狱（ch1-2）→ **10年·秋** 穿山林/到兴城/与林玄影相认和解（**ch2-15 全是秋**）
  - 10年·秋末入冬 蛰伏期、出发西蜀（**ch16 之后**）
  - 11年·春 返兴城（卷二 ch26）；11年春夏 布局；12年夏秋 卷三主体
- **正文可数时长**：越狱→ch13 祭拜 ≈ 2-3 周。中间无"过了几个月"的跳跃。
- **校验方法**：本章季节描写要和相邻章 + 时间轴一致。**回忆里的季节**（童年冬夜、十年前春天桃花）不算当下季节，可保留。
- **已核对改定**：ch13/14/15 是连续两天内、**全是秋**（ch13 祭拜后白日进城=ch14 开头同一天→ch14 尾书房夜谈→ch15 同一夜→ch15 尾"明天一早走"，中间无跳跃）。ch14/15 原写的"冬日/光秃秃的树/夜风冻僵"已全部改秋。**入冬要等 ch16 黄简离兴城、出发西蜀之后**——旧版曾写"ch14 补入冬"，作废，勿照做。

### 3. 碎句 / 单字谓语 / 省略主语过多（AI 味变体，本卷高发）
- **症状**：一个连贯动作被切成多个短句、逐帧慢放，且省主语、堆单字谓语。
  - 差："手抬了起来。/ 抬到一半，停住了。/ 然后收了回来。"
  - 好："手抬起来又收了回来。"
  - 差："打盹，眼皮抬了一下，扫了他一眼，没拦。"
  - 好："听见脚步声抬了抬眼皮，见是个不起眼的行脚人，也懒得盘问，由他出去了。"（补主语+因果链）
- **改法**：合并成有主语、有因果的连贯句。
- **保留例外**：情绪/张力节点的刻意短句留着——喝止（"松手。"）、语塞（"他说不出来。"）、冷冽收尾。判断：这个短是**有张力功能**还是**只是把话切碎**。

### 3-B. 主语与指代（清晰但不啰嗦）
- **同一主语连续**：用代词或承前省略，不反复堆全名（别每句"黄简……黄简……"，该用"他"就用"他"）。
- **主语一切换，立刻用名字点明**——尤其双人场景，避免"他看着他""他的手碰到他"这类两个"他"指不同人、读者要停下来判断的句子；该用名字消歧。
- 与第3类配套：省主语要省得读者不迷路；指代要指得清。与 P-14（叙述用全名、不用单字"林""黄"）一致。
- 目标：主语始终清晰，又不冗余。

### 4. 破折号（本卷每章 20-32 处，重头）
- **夹注式全改**（"X——补充说明X" → 逗号/句号/断句）。
- **只保留**：对话被打断（"你他娘的——"）、说话中停顿（"你额角那道疤——"）。引出直接引语的破折号也尽量改掉。
- 目标：每章 ≤2-3 处，且都是真中断。

### 4-B. 分隔符 `---`（非必要必去）
- **能不用就不用**。第13章曾有 7 处，全部去掉改自然过渡。
- 判断：它分隔的是不是"必须靠分隔符才能跳"的大断裂？如果只是同一场景的连续推进，或可用一句时空过渡（"回城的路上""他出了客栈"）带过的小跳转——**去掉**。
- 去掉后把接口顺好：让上一段末句和下一段首句直接衔接，或补一句过渡。
- 目标：每章尽量 0，除非真有大幅度的时空/视角断裂。

### 5. 红线句式（constitution §2.3，必清零）
- "不是A而是B" / "不再是A而是B" / "没有X是Y" / "不是A，是B" 变体——**全部重写**，改成正常陈述或白描。
- "仿佛整个世界" / "在这个…的世界里" — 直接删。

### 6. 情绪元描述（P-53，写管理情绪≠写情绪）
- "情绪涌上来又压下去" / "有什么东西往上涌" / "先按下不动" / "堵着一团东西上不来下不去" — 重写。
- 三步：命名具体情绪 → 找这个角色压制它的具体方式 → 只写行为，不写"压"这个动作。
- 反例已改："把胸口翻涌的东西压下去" → "伸手抹了把脸"。

### 7. AI 比喻 / 伪具体 / 大词
- 明喻套路（"涩得像砂纸磨过""像一扇关死的门""像唯一还活着的东西"）→ 删或换实写。
- 伪具体（"精致的""说不清道不明的滋味""复杂的眼神"）→ 换携带信息的细节，或留白。
- 大词（"威压""气势逼人""沉甸甸的分量"）→ 行为/物理细节。
- 单字名词化（"这份轻""那份沉"）AI 味重 → 用正常双音节词。

### 8. 重复已知 / 废话（P-54 / P-12）
- 读者已看过的信息不复述（结尾别总结前文事件清单；祭品/坟状写过一次不重复）。
- 动作后缀的多余解释删（"掌心的印子，是指甲硌的，没破" → "掌心攥出几道浅白的印子"）。
- 三选一的原因分析排比删（"不知是坐太久，还是伤太重，又或者没吃东西"）。

### 9. 信息边界 / 逻辑（P-01/P-02，降智红线）
- 角色只能用**已知信息**判断。背对着的人看不到对方表情；没渠道获取的名字不能说出口；不知对方底细就不能替他断定家产。
- 因果不能倒：如"林玄影一直在查"（主动赎罪）≠"黄简让他查他才查"（被动工具人）。
- 数量/方位/身份等硬信息前后一致（坟的数量、进城/出城方向、谁在场）。

### 10. 反复动作/情绪 & 不推进内容（可删）
两条独立的删除检验，用「删除判断三问」逐段过：
- **反复（重复就删/换）**：同一个动作/情绪反复出现——手收紧、又靠门框、再一次喉结滚、又"顿了一下"。第 N 次出现就删掉或换个写法。grep 高频词（收紧/攥/靠门框/喉结/沉默/顿了一下…）看有没有扎堆。
- **冗余（不推进就删）**：不推进剧情、不揭示新信息、不符合人设的反应——即便不重复，套路生理动作（无谓的"喉结滚动""深吸一口气"）、可有可无的过渡段、替读者做的分析旁白，都删。
- **句式模板反复（换着写）**：不只词重复，**句子结构**重复也要抓——多处"X了X了"（攥了攥、顿了顿）、"他V着N"、"一N接一N"、"越来越X，越来越Y"。同一模板一章冒好几次就换掉。grep 骨架示例（按需替换模板）：
  ```bash
  grep -nE '了.{0,3}了|越来越.{1,4}越来越|一.接一.|不.不.，不.不.' "$f"
  ```
- 判断：删掉这段丢不丢东西？丢不了 → 删；丢得了 → 它和前后有真实因果，留（或强化因果）。

## 三、角色声音速记（P-50，对话去同质）

- **黄简/黄繁**（商人，有算计）：说话有目的，绕，用反问试探，不轻易下结论。冷静时"不高不低不急不缓"。
- **林玄影**（落魄商家子，愧疚）：措辞谨慎，易停顿，话说一半，攥衣角，不敢问重。
- **周顺**（底层少年，倔）：短句，省主语，不解释，被追问才多说。不用成语。
- **李希音**（傲娇世家子）：带刺，先贬后褒，用否定句表达在意。

## 四、收工标准

四道都过才算完成：
1. **Q0 细纲覆盖** + **Q0-B 反向抽取**（本章该交付的都交付了、没漂移）。
2. **本手册 A 节 grep 全过** + 二节十类问题过一遍。
