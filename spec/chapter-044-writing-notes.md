# 第44章写作笔记：陈段落经验（供第45章复用）

## 一、L145之后陈的情绪逻辑链

**从“察觉到异常”到“拔刀”之间的过渡，必须经过以下步骤：**

1. 感官信号逐个抵达（气味→灰），每个都单独呈现，不让它们同时出现
2. 两个信号合并判断：“气味。然后是灰。”→ 确认窗外有人来过
3. 确认之后不是“排查是谁”，而是“不管是谁”——恐惧来自不确知
4. 拔刀是**防御本能**，不是推理结论

**拔刀的正确写法（色厉内荏）：**
- 动作：手伸进包袱→拔鞘→看刀刃→搁案角→刀尖对窗
- 内里：写他“没握过刀”这个事实——不需要说他怕，事实本身就够
- 关键动作收尾：`做完这个动作，他盯着自己的手看了一眼，把手收回案上` ——拔刀之后的不自信才是重点

## 二、第44章→第45章的情绪衔接

**44章末陈的状态（第45章起点）：**
- 知道窗外有人来过（两个物理证据）
- 不知道是谁、不知道什么时候（不确定本身就是恐惧）
- 色厉内荏：匕首已摆好，但手在案上——不是握着
- 等子时但**不确信**子时还来不来得及

**45章需要接住的：**
- 返魂香燃一个时辰后变浓 → 陈联想法事招魂 → 恐惧升级
- 朱砂符多烧几道大量飘入 → 捻开见红 → 认出符纸灰 → 法事认知确认
- 兑位铜碗拉响 → 声从杀伐方位来 → 陈懂风水 → 三层叠加崩溃
- 崩溃中先泄露关键信息（矿上、军中）→ 察觉人为→ 转为拖延+攻击碎片
- **二十年/靠本事/被卸磨杀驴/账本是保命符 → 全部由陈亲口漏出，不写心理独白**

## 三、本次踩过的坑

| 坑 | 表现 | 正确做法 |
|----|------|---------|
| 静态独词收束 | “静着” | 通过人物感知写环境，不靠独词制造气氛 |
| 气味强行形容 | “淡，但是压人” | 不安来自“气味出现在错误地点”，不是气味本身的属性。写认知错位，不写气味压迫感 |
| 陈逻辑太清晰 | 逐一排查“三皇子/别的皇子” | 确认“窗外有人”但不排查是谁。恐惧在不确定里，不在推理里 |
| 拔刀前缺过渡 | 排查完直接拔刀 | 先确认事实（“窗外有人来过”），再写拔刀是防御本能 |
