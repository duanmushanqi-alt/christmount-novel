# 兴城地理备忘

## 背景依据

- 兴城为北魏州级城市（刺史驻地），规模为中等府城
- 参考古代中国城市规划规律：官府居城北/中轴，商业居南，居住分散
- 本文档基于正文已出现的地点线索整理，供写作参考，不作硬性约束

## 各地点说明

### ① 刺史府（陈伯庸）
- **位置**：城北正中，主轴线上
- **特征**：府邸宽阔，有官署、宅院，门前有卫兵
- **戏剧功能**：权力中心，主角目前需要绕开的地方

### ② 县衙（李县令）
- **位置**：刺史府偏东，规模小于刺史府
- **注意**：李县令是李希音之父；县衙和刺史府是上下级，不在同一建筑内
- **与刺史府距离**：步行约一刻钟以内

### ③ 黄家旧宅（已非黄家所有）
- **位置**：城东北，昔日与林宅属同一富户片区
- **现状**：黄家败落后，宅子已被他人购入或没收，现居他人
- **意义**：黄简回城后不能去，只能远远望一眼

### ④ 林宅（林玄影居所）
- **位置**：城北偏西，与黄家旧宅同属昔日大户居住区
- **特征**：有书房，有正院，有一两个老仆小厮
- **注意**：与林家杂货铺（城南）不在同一处，是两个不同地点
- **黄简夜访**：从偏僻街区到林宅，需穿越城中，走偏僻小路（第26章安排）

### ⑤ 街市（主市集）
- **位置**：城中偏南，东西主街偏南一侧
- **特征**：日常买卖，摊贩集中，热闹，各色人等
- **联络用途**：黄简和周顺约定的信号柱子在街市东侧入口（第28章）
- **黄简身份掩护**：以"陈汉国山货商人"的名义每几日来此买卖，天然合理

### ⑥ 林家杂货铺（城南）
- **位置**：城南街口，毗邻街市
- **依据**：第26章邻居提到"街口的林家杂货铺要重新开张了"；"城南的林家"
- **现状**：第24-25章被人放火（警告），修缮后重新开张（第26章）
- **周顺工作地**：赵掌柜是林家铺子的伙计/经营者，周顺在此做搬货活
- **与街市关系**：步行2-3分钟

### ⑦ 药铺区
- **位置**：偏西南，街市附近
- **使用者**：周顺妈妈带妹妹来配药就在这一带活动
- **注意**：母女遭骚扰不在此处，在城外（见城外地点说明）
- **第27章场景**：妈妈出门取药，在街上认出黄繁，跟上去

### ⑧ 黄繁小院（当前居所）
- **位置**：城西南偏僻街区
- **第26章描述**：邻里清静，住讨生活的小商人或书生，不以独门独院为荣却只能住这里
- **与街市距离**：步行约一刻钟，每次去街市要穿过一段安静街道
- **战略意义**：偏僻，邻居对他失去兴趣；不靠近林宅（避免两家被关联）；租房，半年后计划买下

### ⑨ 土地庙（黄简与周顺碰面处）
- **位置**：城内西偏南，偏僻巷角，距黄繁小院几条街
- **第28章功能**：约定"逢五逢十"碰面地点，不是黄简住所
- **选址逻辑**：城内土地庙多建在居民区巷角，周边清静，来往不引眼；两人各从不同方向过来，无需频繁出城门

## 城外地点

### ⑩ 坟墓区
- **位置**：出西城门往西约半里，一片矮坡，两棵老柏树之间
- **依据**：第13章，林玄影告知方向："往西，半里地左右，一片矮坡，两棵老柏树中间"
- **黄父母坟**：坡面并排两座，朝南；坟前曾有人（林玄影）提前祭扫，摆了桂花糕
- **林父坟**：坡的另一面朝东，隔约百来步；碑前祭品摆法与黄家一致，同一人来过

### ★ 母女遭骚扰地点（第13章）
- **位置**：城外，距西城门约二三百步，路旁岔道，夹在两堵矮墙之间
- **黄简视角**：从城外祭扫返回，"快到城门附近时"在岔道口听到动静，转进去
- **注意**：不在城内，不在药铺附近——母女当时是从外地进城求医途中遭遇，刚到城门外

## ⑩ 刺史府内部布局（第三卷段落七/八）

### 规制依据
- 唐代州府官署标准：前衙后宅，多进院落，中轴线对称
- 兴城为北魏州级城市，刺史府坐北朝南，城北正中
- 建筑群共三进主院 + 西跨院 + 后罩房，规模为中等府城官署

### 各分区说明

| 位置 | 人物/功能 | 说明 |
|------|----------|------|
| **第一进·前衙** | 巡夜值房（东侧廊下） | 巡逻驻点；白天有吏员出入，入夜只剩值夜 |
| **宅门** | 前衙与内衙的分隔 | 入夜后关闭，但可从两侧走廊绕过（不是硬隔离） |
| **第二进·正堂** | 议事、待客 | 陈白天在此见人；入夜无人 |
| **第二进·书房** | 陈伯庸个人空间 | 偏东，远离西厢管事房；有窗户朝南和朝西 |
| **第二进·东厢房** | 顾渔画图处 | 面朝西，开门可见内衙庭院空地；距离正堂约十几步 |
| **第二进·西厢房** | 幕僚/管事 | 多位管事共用，入夜后无人 |
| **内宅门** | 内衙与内宅分隔 | 入夜关闭；后院家眷不参与前衙事务 |
| **第三进·内宅** | 陈与妻室 | 关系不亲近；距离书房远，"前院有事听不到" |
| **后罩房/排房** | 下人杂役住所 | 靠北墙，东西向一排；已有多间空置（管事被派出） |
| **夹道** | 排房与北墙之间的窄通道 | 下人运杂货用；容一人通过；入夜无人 |
| **偏门** | 北墙西角 | 服务性出入口；铁闩从内闩上；临后院窄巷；门前有堆旧木料和破瓦罐 |
| **堆旧木料** | 偏门附近（西南角墙根） | 储物死角；ch43已出现 |

### 巡夜路线与林的关键路径

**巡夜路线**：
- 起点：第一进东侧值房 → 沿廊下至前衙 → 穿宅门旁走廊至第二进 → 正堂前 → 至排房区域（看一眼偏门）→ 返回值房
- 一趟约一刻钟（15分钟）
- 陈遣散多数下人后，巡夜密度降低，每趟之间的间隔拉长，且具体时辰不被计较

**林去偏门的路线**（ch43已踩点）：
偏院（西跨院）→ 侧门 → 第一进 → 正堂拐角 → 穿过正堂东侧 → 北上经内宅门旁 → 排房区 → 堆旧木料 → 偏门

**林接黄后去书房的路线**（ch44）：
偏门 → 堆旧木料 → 夹道（短暂隐蔽/换衣）→ 原路返回 → 穿过第二进内衙庭院（**最暴露段**）→ 正堂东侧 → 书房前的老柏树（就位）

### 老柏树位置
- 书房东南角，距书房窗口约十几步
- 树干粗，两人蹲后刚好被挡住
- 从树下能看见书房南窗和西窗，也能扫到内衙庭院的方向
- 此树为景观树，存在合理（唐代官署庭院多植柏）

### 东厢房视点（顾渔）
- 门朝西开，开门正对内衙庭院空地
- 屋里不点灯时，门外的人看不见室内
- 能看见：内衙庭院（Lin+Huang最暴露段的必经之地）+ 西边廊下（巡夜路线）
- 不能直接看见：偏门、夹道、书房正门

### 林住处·偏院
- 西跨院偏院，不在主中轴线上
- 林被安排在此因为陈不当他一回事（非核心人物）
- 可经侧门自由出入第一进
- 离正堂不远（ch43："偏院离正堂不远，夜里能听见一些白天听不到的声音"）

### 空间逻辑验证
- ✅ 书房在内衙区（第二进），距第三进内宅隔一个内宅门，物理距离支持"前院有事后院听不到"
- ✅ 偏门在最后（排房区/西北角），属于后院范畴，远离第二进
- ✅ 林从偏院到偏门需要经过正堂拐角→排房，路程长但可行
- ✅ 顾渔在东厢房（第二进）能看见内衙庭院，但这个位置距离偏门很远——他看到的不是"开门那一瞬间"而是"返回时穿过内衙庭院"
- ✅ 巡夜从第一进值房出发，到排房区域时正好和林黄路线有交叉的可能

## 兴城以西村庄（周顺原居地）

- **位置**：兴城西，往宣城方向
- **特征**：普通农村，距兴城约一两天路程（不能太近——父亲去"隔壁镇看活计"而非直接来兴城，说明兴城对他们不算顺路；母亲最终带孩子来兴城求医，说明还走得到）
- **距离调整说明**：共识文档原设"半天路程"偏近，已修正。父亲当年"去隔壁镇而非兴城找活计"在逻辑上支持更远的距离
- **与招工线的关系**：第24章招工在兴城"南边村子"，但方向也指向宣城——父亲当年"去隔壁镇看活计"后失踪，该镇方向即为宣城方向，与"洗人"行动路线吻合
- **地名**：待确认，可暂用"兴城以西某村"
